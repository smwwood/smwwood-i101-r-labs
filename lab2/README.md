# INFO-I101 R Lab Day 2

Upload these files as `/lab2/` in `smwwood/smwwood-i101-r-labs`.

Preview by opening `index.html` directly, or for more reliable local hosting run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000/`. webR and jsPDF require an internet connection.

The CSV and helper code are embedded in the HTML for local preview and also provided as separate files for downloads/reuse. All interactive cells use one shared webR session. Students export their code, results, and answers as PDF for Canvas.

The I101 helper `filter_rows(data, condition)` intentionally uses a descriptive name to avoid confusion with `stats::filter()`, which has a different meaning in base R.
