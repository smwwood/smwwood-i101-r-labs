Part 4

Part 4: Data types

Different kinds of values let us do different things in R.

A value's data type tells R what kind of information it is — and that affects what R can do with it.

For example, R can print() numbers, text, and logical values. But some operations only make sense for certain types. We can do arithmetic with numbers, but trying to add a number to a person's name does not make sense.

What about logical values?
Logical values are TRUE or FALSE. R can actually use them in arithmetic: when necessary, TRUE acts like 1 and FALSE acts like 0. That can be useful, but their more important job is helping R make decisions.

Logical values are especially useful whenever we want to do something if a condition is true. For example:

  • Print a student's name if they earned the highest pre-test score.
  • Keep an observation in a dataset if its value is below 1,000,000.

In both cases, R first needs a question that can be answered with TRUE or FALSE.

Part 5

Part 5: Vectors

Store many values together in one variable.

You've already used functions earlier in the course. A function takes one or more inputs, performs an algorithm, and produces an output. R comes with many useful pre-written functions for basic math and statistics, including sum(), mean(), median(), min(), max(), and summary().

Think of a function as a reusable mini-algorithm: give it some data, let it do the work, and use the result it returns.
